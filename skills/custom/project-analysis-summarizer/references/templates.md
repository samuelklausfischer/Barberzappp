# Templates (Project Analysis Summarizer)

## PROJECT_SUMMARY.md

- What is this repo?
- What are the deliverables (apps)?
- Tech stack (per app)
- How to run locally (fast path)
- Environments & config (where are env vars)
- Key integrations
- Current status / next milestones

## REPO_MAP.md

- Tree (depth 3-4)
- Folder index (what each top folder does)
- Important entrypoints

## ARCHITECTURE.md

- Components diagram (text)
- Data flow (requests/webhooks/jobs)
- Auth model
- Multi-tenant model
- External services

## RUNBOOK.md

- Prereqs
- Setup
- Dev commands
- Build commands
- Deploy notes
- Ports
- Env vars list (names only)
- Troubleshooting

## DECISIONS.md (ADR-lite)

For each decision:
- Date
- Decision
- Why
- Alternatives considered
- Consequences
