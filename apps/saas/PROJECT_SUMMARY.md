# apps/saas — Project Summary (BarberZap Pro)

## O que é
Aplicativo SaaS “BarberZap Pro”: plataforma de gestão para barbearias com IA, financeiro e WhatsApp.

## Stack
- Frontend: React + TypeScript + Vite + Tailwind
- Backend: Python (`backend/`)
- Database: Postgres/Supabase (`database/` com RLS, índices, outbox, search, etc.)

## Como rodar (dev)
- `cp .env.example .env.local`
- `npm install`
- `npm run dev`
