📋 TIPOS DE ERRO:

Frontend
────────────────────────────────────────────────────────────────────────────
  NetworkError         - Problemas de conexão, timeout
  TimeoutError         - Requests que demoram muito
  ValidationError      - Input do usuário inválido
  AuthError            - Login/falha de autenticação
  TokenExpiredError    - JWT/token expirou
  NotFoundError        - 404 - recurso não encontrado
  ConflictError        - 409 - conflito (double-booking)
  ServerError          - 500 - erro no servidor
  UnknownError         - Catch-all para erros inesperados

Backend (Python)
────────────────────────────────────────────────────────────────────────────
  ValidationError        # 400 - dados inválidos
  AuthenticationError    # 401 - não autenticado
  TokenExpiredError      # 401 - token expirado
  AuthorizationError     # 403 - sem permissão
  NotFoundError          # 404 - não encontrado
  ConflictError          # 409 - conflito
  InternalServerError    # 500 - erro interno
  ServiceUnavailableError # 503 - serviço indisponível

🚀 QUICK START:

Frontend (TypeScript/React)
────────────────────────────────────────────────────────────────────────────
  1. O main.tsx já está atualizado com ErrorBoundary:
     import { ErrorBoundary } from '@/error';
     
     <ErrorBoundary>
       <App />
     </ErrorBoundary>

  2. Usar erros em código:
     import { ValidationError, NetworkError, handleError } from '@/error';
     
     // Criar erro
     throw new ValidationError('email', 'Email inválido');
     
     // Tratar erro
     try {
       await someAsyncOperation();
     } catch (error) {
       handleError(error, { component: 'MyComponent', action: 'loadData' });
     }

  3. Ver métricas (console em dev):
     (window as any).errorLogger.getMetrics()

Backend (FastAPI)
────────────────────────────────────────────────────────────────────────────
  1. No seu main.py:
     from fastapi import FastAPI
     from error import create_error_middleware, create_logging_middleware
     
     app = FastAPI()
     create_error_middleware(app, framework="fastapi")
     create_logging_middleware(app, framework="fastapi")

  2. Usar em endpoints:
     from error import validate_and_raise, ValidationError, ConflictError
     
     @app.post("/appointments")
     async def create_appointment(data: dict):
       validate_and_raise(
         data.get('shop_id'),
         ValidationError,
         "shop_id is required"
       )
       
       if check_conflict(data['shop_id'], data['time']):
         raise ConflictError("Time slot already booked")
