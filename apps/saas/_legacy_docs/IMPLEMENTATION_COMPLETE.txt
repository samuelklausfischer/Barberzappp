QUICK START
================================================================================

1. Integrate ThemeProvider:
   Edit /root/barber/src/app/main.tsx
   Add <ThemeProvider defaultMode="dark"> wrapper

2. Import components:
   import { AnimatedCard, PageTransition, LoadingSkeleton, 
            ButtonAnimated, Tooltip } from '@/components/ui';

3. Use in your code:
   <PageTransition>
     <AnimatedCard variant="gold" glow hoverable>
       <ButtonAnimated onClick={handleClick}>Click me</ButtonAnimated>
     </AnimatedCard>
   </PageTransition>

4. Start development:
   cd /root/barber
   npm run dev
