# 🔧 Scripts Utilitários

Scripts avulsos usados para operações de suporte ao BarberZap.

| Arquivo | Linguagem | Função |
|---|---|---|
| `organizar_lista_meta.py` | Python | Limpa e organiza listas de leads para Meta Ads |
| `supabase_github_integration.py` | Python | Integração CI/CD entre Supabase e GitHub |
| `visitor_webhook.py` | Python | Webhook receptor de dados de visitantes |
| `visitor-tracker.js` | JavaScript | Script de tracking de visitantes (client-side) |
| `supabase_github_schema.sql` | SQL | Schema do banco para a integração GitHub |
| `supabase_visitors_schema.sql` | SQL | Schema do banco para tracking de visitantes |

> ⚠️ Estes scripts são utilitários independentes — não fazem parte do frontend React.
