# 🐳 Infraestrutura

Arquivos de configuração para deploy e CI/CD.

| Arquivo | Função |
|---|---|
| `Dockerfile` | Imagem Docker do projeto |
| `docker-compose.yml` | Orquestração multi-container |
| `github_actions_workflow.yml` | Pipeline CI/CD do GitHub Actions |
| `.htaccess` | Regras de redirecionamento Apache |
| `default.php` | Página padrão PHP (fallback) |
| `requirements.txt` | Dependências Python principais |
| `requirements_github_integration.txt` | Dependências Python para integração GitHub |
