🔣 FUNÇÕES DISPONÍVEIS
════════════════════════════════════════════════════════════════

PRINCIPAIS:
  resolve_tenant(instance_name, check_active=True)
    → Resolve tenant verificando se está ativo

  resolve_tenant_safe(instance_name)
    → Resolve sem levantar exceções (retorna None)

  resolve_tenant_cached(instance_name)
    → Resolve usando cache LRU (muito rápido)

AUXILIARES:
  get_tenant_instance_info(instance_name, user_id=None)
    → Obtém informações completas da instância

  is_instance_active(instance_name)
    → Verifica se instância está ativa (bool)

  list_tenant_instances(user_id, active_only=True)
    → Lista todas as instâncias de um tenant

  validate_tenant_access(instance_name, expected_user_id)
    → Valida se instância pertence ao tenant

EXCEÇÕES:
  TenantResolutionError
    → Erro base para resolução de tenant

  TenantNotFoundError
    → Instância não encontrada no banco

  TenantInactiveError
    → Tenant está inativo

💡 EXEMPLO DE USO

from core import resolve_tenant_cached

@app.post("/webhooks/whatsapp")
async def webhook(request: Request):
    payload = await request.json()
    instance_name = payload.get('instanceName')
    
    # Resolve tenant (com cache para alto desempenho)
    user_id = resolve_tenant_cached(instance_name)
    
    if not user_id:
        return {"error": "Invalid instance"}
    
    # Agora você tem o user_id para:
    # - Buscar configuração do tenant (agente_config)
    # - Registrar leads no CRM (crm_leads, crm_messages)
    # - Gerar respostas IA personalizadas
    # - Enviar via Evolution API
    
    return {"status": "ok", "user_id": user_id}
