🚨 O Risco Atual (SPA React)

  • ✖ Duplicação de PageView: Em SPAs, trocar de rota ou re-renderizar componentes pode disparar o 'PageView' múltiplas vezes se estiver dentro de um `useEffect` mal configurado.
  • ✖ Perda de Referência: Se o script estiver apenas no `index.html` e não houver uma "ponte" no React, perdemos o rastreamento de cliques em botões dinâmicos.
  • ✖ Dados Pobres: Enviar apenas o evento sem parâmetros (ex: valor, moeda, nome do conteúdo) diminui a inteligência do algoritmo do Facebook.

✅ A Solução Blindada

  • ✔ Híbrido Inteligente: Mantemos o script base no `index.html` para garantir carregamento ultra-rápido (First Paint), mas controlamos os eventos específicos via React.
  • ✔ Utility Wrapper: Criaremos um arquivo `pixel.js` que "encapsula" o `window.fbq`. Se o Pixel não carregou (AdBlock), o site não quebra.
  • ✔ Enriquecimento de Dados: Vamos adicionar `value`, `currency` e `content_name` nos eventos de conversão.

Implementação Técnica Recomendada

1. Camada de Abstração (src/utils/pixel.js)

Este arquivo protege o código. Ele verifica se `window.fbq` existe antes de tentar enviar dados, evitando erros "fbq is not defined".

export const PIXEL_ID = '1757123869009394'; export const trackEvent = (name, data = {}) => { if (typeof window.fbq === 'function') { window.fbq('track', name, data); } else { console.warn('Pixel não carregado ou bloqueado.'); } };
