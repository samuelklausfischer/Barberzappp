Guia de Conversões Personalizadas

Siga estes passos para configurar o Meta Ads para o BarberZap

1

Evento: Ver Conteúdo (ViewContent)

Use isto para rastrear pessoas que rolaram até a seção de preços ou viram sua oferta principal.

01 - Visualizou Preços - BarberZap Usuário chegou na seção de ofertas da Landing Page. BarberZap (Seu Pixel) Ver conteúdo

Regras (Importante):

Como seu site é uma página única, use a regra de URL para garantir que o evento conte apenas no seu domínio:

URL
contém
/ (ou o seu domínio: barberzap.com.br)
2

Evento: Iniciar Compra (InitiateCheckout)

Este é o seu evento mais valioso antes da venda. É disparado quando clicam no botão de "Assinar".

02 - Iniciou Checkout - Clique Botão Assinar Potencial cliente clicou para escolher um plano e ser redirecionado. Iniciar finalização de compra

Regras:

URL contém /

Inserir um valor de conversão:

Marque esta opção para o Facebook saber quanto você ganharia com essa assinatura.

49.90 (ou o valor do seu plano mensal)

DICA DE OURO PARA REACT

No Meta Ads, se o seu Pixel estiver instalado corretamente via JavaScript (como fizemos no pixel.js), você não precisa se preocupar com a URL mudando. O Meta vai identificar que o evento Ver conteúdo foi disparado via código. A regra "URL contém /" serve apenas para o Meta validar que a conversão pertence ao seu site.
