1. Camada de Abstração Segura (Anti-Crash)

Criamos um arquivo dedicado (src/utils/pixel.js) para gerenciar todas as chamadas do Pixel. Ele envolve o código em um bloco de proteção (try-catch).

  • Previne a "Tela Branca" se o script do Facebook falhar.
  • Permite que o site funcione mesmo com AdBlockers ativos.
  • Removeu referências antigas a process.env que quebravam o build.
// src/utils/pixel.js export const trackEvent = (name, data = {}) => { try { if (typeof window.fbq === 'function') { window.fbq('track', name, data); } } catch (error) { // Falha silenciosa: O site nunca quebra } };
